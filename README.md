# Smart Home Project

## Overview

Smart Home is a modern, professional platform that connects users with top-notch home decoration and consultation services. It allows users to browse, book, and pay for various home decoration services securely. The platform also offers a dashboard for users and admins to manage services, bookings, and user roles effectively.

## Features

### User Features

* Browse a wide range of decoration services.
* View detailed service descriptions, prices, and images.
* Book services with preferred dates.
* Make secure online payments using Stripe.
* Access a personal dashboard to manage bookings and payments.

### Admin Features

* Manage all users, their roles, and decorator requests.
* Approve or reject decorator requests.
* Manage services (add, edit, delete).
* Monitor bookings and payment statuses.
* Access analytics and statistics of service bookings.

### Decorator Features

* Apply to become a professional decorator.
* Manage assigned services and bookings.
* Track payment status for completed services.

## Tech Stack

* **Frontend:** React, Tailwind CSS, React Router, React Hot Toast, React Query
* **Backend:** Node.js, Express.js, Firebase Admin, JWT for authentication
* **Database:** MongoDB
* **Payment Gateway:** Stripe
* **Deployment:** Vercel (Frontend), Node.js Server (Backend)

## Pages

* **Home:** Browse popular services, view about section, and mission statement.
* **About:** Professional overview of the platform.
* **Contact:** Interactive form with phone, email, and location details.
* **Services:** Detailed listing of available home decoration services.
* **Service Details:** Individual service information with booking option.
* **Coverage:** Areas and cities served.
* **Dashboard:** User-specific dashboard to manage bookings, inventory, and profile.
* **Payment Success:** Confirmation page after successful payment.


## Security

* JWT authentication for secure access.
* Firebase Admin for server-side authentication.
* Secure payments via Stripe.
* Role-based access control for admin, users, and decorators.

## Future Enhancements

* Add real-time chat support between users and decorators.
* Implement AI-based service recommendations.
* Multi-language support for global users.
* Progressive Web App (PWA) features for offline access.
